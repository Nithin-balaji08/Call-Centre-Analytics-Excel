Call Centre Performance & Customer Analytics Dashboard


Project Overview
This project analyzes call centre performance and customer interactions using Microsoft Excel. The objective is to transform raw call-centre data into meaningful business insights through data cleaning, analysis, PivotTables, KPIs, and an interactive dashboard.
The analysis focuses on call volume, purchase amount, call duration, representative performance, and customer satisfaction.

Project Objectives
•	Analyze overall call centre performance.
•	Track call volume and customer interactions.
•	Analyze total purchase amount generated through calls.
•	Evaluate customer satisfaction ratings.
•	Compare performance across representatives.
•	Analyze call duration and duration categories.
•	Identify trends by financial year and day of the week.
•	Build an interactive Excel dashboard for business reporting.

Dataset
The dataset contains approximately 1,000 call-centre records.

Key Columns

Column	Description

Call Number -	Unique identifier for each call
Customer ID	- Unique customer identifier
Duration	- Call duration
Representative -	Representative handling the call
Date of Call	- Date on which the call occurred
Purchase Amount -	Amount associated with the customer interaction
Satisfaction Rating	 - Customer satisfaction score
FY	- Financial year
Day of Week -	Day of the call
Duration Bucket	- Categorized call duration
Rating Rounded	- Rounded customer satisfaction rating

Data Preparation
The raw dataset was prepared in Excel before performing the analysis.
Key preparation activities included:
•	Reviewed the raw dataset for consistency.
•	Checked data types and formatting.
•	Created calculated columns.
•	Created Financial Year classification.
•	Extracted Day of Week from the call date.
•	Created Call Duration Buckets.
•	Rounded satisfaction ratings for analysis.
•	Structured the dataset for PivotTable analysis.
